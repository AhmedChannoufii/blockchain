# Blockchain : apprendre pas à pas avec Python

Ce dépôt rassemble les travaux pratiques d'un cours de Blockchain.
Chaque TP est expliqué et accompagné de code Python que tu peux lancer et modifier.
L'idée : comprendre comment ça marche en le programmant toi-même.

## Pour qui ?

Pour toute personne qui veut comprendre la blockchain, même sans expérience.
Les bases de Python suffisent pour commencer.

## Prérequis

- Python 3 installé
- Un éditeur (VS Code, PyCharm ou Jupyter Notebook)
- Aucune bibliothèque externe à installer

## Parcours conseillé

| TP | Thème | Ce que tu vas apprendre |
|----|-------|-------------------------|
| TP1 | Introduction | Les bases et le vocabulaire de la blockchain |
| TP2 | Blockchain simple en Python | Hachage SHA-256, blocs, chaînage, vérification de l'intégrité |
| TP3 | Minage et Proof of Work | Preuve de travail, nonce, difficulté, coût d'une falsification |

D'autres TP seront ajoutés au fil du semestre.

## Comment utiliser ce dépôt

1. Clone le dépôt :
```bash
   git clone https://github.com/AhmedChannoufii/blockchain.git
   cd blockchain
```
2. Ouvre le dossier d'un TP (par exemple `TP2`).
3. Lis son `README.md` pour comprendre la théorie.
4. Lance les exercices dans l'ordre :
```bash
   python exercice1.py
```
5. Modifie le code, relance, observe ce qui change.
